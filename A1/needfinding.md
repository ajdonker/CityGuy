CityGuy helps people discover the right public spaces for what they want to do, while providing fresh, community-verified information about their current conditions, hazards, and accessibility.

# CityGuy gives you the right place for the right time ! 
## 1. DOMAIN - SMART LIVING 
Community platform for discovering, rating and monitoring public spaces.
## 2. 3-4 DEEP USER NEEDS 
- public/non private space -activity RECOMMEND. 
People need to find public spaces that are suitable for a specific activity, rather than simply finding the nearest park or square.
ex in covid abandoned rooftops were popular for meetups/parties. List of child/dog friendly places for parents/dog owners.
    1. Search for closest places that suit supplied user activity.
    2. Search for the most suitable places in the application database according to user activity. 
    3. Allow users to add tags: recommendation, suitable for _ to specific places.
    4. Trust system based on user history/past tags. 
    5. Add users personal needs to the context ex. accesibility or dog and filter places with them. 
    6. Rank all places based on all context. Return 3 alternatives.
- CHECKING/WARNING FOR verified hazards. informing whether place is safe/usable/reachable. ex find out if cycling path till location is blocked, or playground is temporarily closed due to repairs. Users can report location and type of "hazard", a trust system can be implemented so enough trusted users verify the hazard -> it gets reported to local authorities for example. Hazards can  be shown on the map to users esp linked to certain activities, want to cycle maybe the path is blocked. 
    1. Confirmed warnings show to users that are doing relevant activities ex. cycling nearby. 
    2. Allow for civic reporting to authorities. 
    3. Allow user to add warning/dangerous tags to specific places.
    4. Keep unverified per trust hazard/warning reports out of normal view on the app, and age old reports out.
    5.
- UNDERTSTAND how place CHANGES OVER TIME. ex. time of day, crowd level, event, weather, temporary conditions. 
    1. live crowd reporting.
    2. event awareness.
    3. suitability for activity from user.
    4. smart notifications about conditions along the path and on the place.
    5. historical time pattern for all conditions.
- help citizens PARTICIPATE in improving the community. Allow for coordination with other users, ex. broken bench that needs to be fixed can be reported/discussed?.
    1. issue tracking 
    2. community can decide places it can maintain/repair itself. 
    3. expertise by cathegory - user that participates in bike trail ratings has greater trust in bike trail related tags than on other areas. 
    4. allow for confirmed local authority/ politics roles in the system that carry more weight on this need.
